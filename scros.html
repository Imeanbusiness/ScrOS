Scr-OS Manual

Getting started

Basics

Scr-OS is a browser-based desktop simulation with a clock, command panel, and app dock.

  1. Clock
    Shows the current time. By default it is set to 24-hour format. Use the >fclock command to switch formats.
  2. Command Output
    Displays the result of commands entered in the command panel.
  3. App Dock
    Click icons to open apps quickly. Use the arrows to flip pages. Customize the dock position and app slots. Click an icon to open it on top of Scr-OS. Hold CTRL and click to open a new tab.
  4. Command Panel (Input)
    Enter commands here. Terry analyzes your request and shows output in the command area.

Functions

Quick Research
In chat mode, Terry can access Google searches. You must provide your own API key for some chat features.

Convenience
Terry can open websites and search Spotify or YouTube directly.

Commands
Use commands to control Scr-OS behavior, open apps, and change settings.

Customization
Commands let you change the background, icons, font style, and other UI settings.

Issues

If you find bugs or issues, report them on the Scr-OS GitHub page. Run >gh to open the repository.

Commands

🎨 Customization

CommandDescription
>bgc (filename)Set the background image to a file from the Images folder. Example: >bgc BG2.png
>vbgc (filename)Set the background video file from the Videos folder.
>bgmodeToggle between animated and static backgrounds.
>fontcolor (color)Change the font color using a hex code or CSS color name.
>outlcolor (color)Change the font outline color.
>font (font name)Set the font family. Example: Nunito, Arial.
>iconpack (folder name)Change the icon set. Add icons in the format AppIcons/AppName.png.
>remove (slot)Remove an app from the current dock page slot (1–10).
>replace (slot) (appname)Replace a dock slot with another supported app.
>showclockToggle the clock display.
>showsecondsToggle seconds on the clock.
>showdockToggle the app dock.
>switchdockSwitch dock and input positions.
>pgs (pages)Set the number of dock pages (1–4).
>dockmodeToggle between fluid and simple dock modes.
>lockdockLock the fluid dock in place.
>appadd (appname)Add a custom supported app. Paste the destination link when prompted. Add an icon to the active icon pack.
>appremove (appname)Remove an app from the supported list.
>inpos (x value) (y value)Move the input box to a custom screen location. Coordinates are percentages.
>outnpos (x value) (y value)Move the output box to a custom screen location.
>clocknpos (x value) (y value)Move the clock to a custom screen location.
>outputsize (font size)Resize the output font (8–150).
>clocksize (font size)Resize the clock font (8–300).
>docktopoffset (offset in %)Adjust the dock's vertical position when it is on the left or right.
>toggleterryHide or show Terry.

🛠️ Assistance

CommandDescription

🔍 Search & Web

CommandDescription
>gs (query)Search Google for the provided query.
>yt (query)Search YouTube for the query.
>ms (query)Search Spotify for the query.
>ops (site)Open a website. Example: >ops amazon.com.

⚙️ System Utilities

CommandDescription
>calc (expression)Evaluate math expressions. Supports functions like sqrt, sin, pi, and log.
>calcds (maximum denominator)Set the maximum denominator for fraction simplification (1–1000).
>fclockToggle between 12-hour and 24-hour clock formats.
>textms (delay)Set command text output delay in milliseconds (0–100).
>apiEnter your own API key for chat features.
>reloadReload Scr-OS.
